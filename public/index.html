About Web Inspector

      

        Web Inspector is a lightweight, production-ready website status and HTML inspection dashboard designed for developers, DevOps, and webmasters.
      


      
Features

      
    
        
  • Accurate HTTP response status, redirect chain tracing, and latency metrics
    • 
        
  • Strict Server-Side Request Forgery (SSRF) and DNS rebinding protections
    • 
        
  • Comprehensive HTML metadata, headings hierarchy, and simplified DOM structure tree
    • 
        
  • Technical SEO analysis (meta descriptions, canonicals, image ALT attributes, JSON-LD)
    • 
        
  • Security header auditing (HSTS, CSP, X-Frame-Options, Referrer-Policy) and masked cookie reporting
    • 
        
  • DNS records lookup (A, AAAA, CNAME, MX, TXT) and public TLS certificate validation
    • 
        
  • Syntax-highlighted HTML viewer with search, copy, download, and fullscreen modes
    • 
      


      
Technical Architecture & Limitations

      

        This tool fetches the actual server-delivered HTTP response. It does not run a headless browser instance; therefore, content rendered exclusively by client-side JavaScript Single Page Applications (SPAs) will not appear in the HTML source.
      


      

        🔒
        Inspections are processed strictly in memory. Inspected HTML and cookies are never stored permanently.
      

    

  


  
  

    

      
      
Web Inspector REST API

      

        You can inspect websites programmatically by calling the JSON API endpoint.
      


      
Endpoint

      

        GET /api/inspect?url={target_url}
      


      
cURL Example

      

        
curl "https://web-inspector.herokuapp.com/api/inspect?url=https://example.com"

        
      


      
Rate Limiting

      

        The API enforces rate limiting of 30 inspection requests per 10 minutes per IP address. Standard headers (RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset) are included in all responses.
